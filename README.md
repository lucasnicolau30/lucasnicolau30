### About me

Full Stack Developer at Grupo Bringel, working with TypeScript, React, Next.js, Nest.js, Python, Django and PostgreSQL to build web systems end to end.

Before writing production code, I spent almost a year as a QA / Test Automation Engineer at RedMaxx, where I built a custom test automation framework in Python + Pytest for REST APIs, achieving 98% test coverage across positive/negative scenarios, status codes, and JSON structure validation, with automatic CSV report generation.

That obsession with quality became a tool: I created [`sentry`](https://github.com/lucasnicolau30/sentry), a Python CLI published on PyPI as `sentry-test`, which audits test coverage and quality from the code diff and issues an auditable verdict, fully local, with AI-agent integration (Claude Code).

I also volunteered as a Full Stack Developer on PACE 2025 (a UFAM extension project), building a real-world web application integrated with the Google Sheets API, used by UFAM's School of Dentistry in scientific research, and worked as a Teaching Assistant for Algorithms & Data Structures I and Linear Algebra I.

Still finishing my Software Engineering degree at UFAM, but my focus today is building things that work in production, tested, and built to last.
